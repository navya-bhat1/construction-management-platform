# Construction Management Platform

A cloud-native construction management application built using FastAPI, Docker, and Kubernetes.

## Tech Stack
- FastAPI
- Docker
- Kubernetes
- Minikube
- GitHub

## Features
- Task Management API
- Health Check Endpoint
- Containerized Deployment
- Kubernetes Deployment & Service

## Run Locally

docker build -t construction-platform .
kubectl apply -f k8s/
